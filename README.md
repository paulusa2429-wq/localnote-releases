# LocalNote — Release Downloads

This repository hosts **installer downloads for LocalNote** — binaries only. There is no source code here; LocalNote's source lives in a private repository.

## What is LocalNote?

LocalNote is an offline, privacy-first meeting-notes app for your computer. It records, transcribes, and organizes your meetings entirely on your own machine — no account, no cloud, no telemetry. Your meetings never leave your computer.

## Download

Grab the latest installer from the [Releases](../../releases) page:

- **macOS** — download the `.dmg`, open it, and drag LocalNote into Applications.
- **Windows** — download the `.exe` installer and run it.

LocalNote also checks for updates itself (Settings → Updates inside the app), so once you have it installed, new versions arrive automatically.
